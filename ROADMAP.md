# Roadmap

The next useful milestone is memory that recalls related experiences and remains useful under a finite storage budget. Current exact-recall new-scene usefulness failed; a software replacement primitive does not yet provide native allocation.

1. Qualify supported similarity readout and ambiguity/abstention without changing learned connections.
2. Build a native destination selector and conditional replacement, protecting other memories. The five-record allocation-pointer design is assessed only.
3. Freeze a fresh integrated stream study with strong controls before enrolling new scenes. Preserve original-physics behavior, recall precision/coverage and protected memory.
4. Capture actual input, returned decision, connection edit and later recall, keeping derived activity and reconstructed scenes explicit.

No experiment is launched by this roadmap. Earlier campaigns remain closed. [Current evidence](docs/STATUS.md), [downloads](docs/REPRODUCING.md), [historical roadmap](docs/history/roadmap-through-20261025.md).
