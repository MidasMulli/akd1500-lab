# Native learning controls native memory admission

Three resident plastic groups across seven sequential FNP3s. One manager record
stores the latest raw observation in its binary connections; its pre-update match
signal controls whether a protected consequence bank receives a teacher event.
An always-updating bank supplies an internal comparison. The host sends raw keys,
uniform phase clocks and delayed actual outcomes. It never chooses a target bank,
record or connection from the manager response. The fixed per-bank query/teacher
clock schedule is still configured by the host.

The repeat-admission rule and fixed representation are designed. The recent-key
state is learned using the existing native swap rule. This is an experimentally
qualified multi-bank control path, not a self-discovered management objective or
an energy/performance advantage over CPUs.

enqueue at an aligned-write guard. Failed CPU designs, compiler probes and
operational stops are recorded separately. Nine validly rehashed corruptions
must fail semantic checks; passing file hashes alone are insufficient.

Five initializations: useful-memory revisit120/120; held-out ordering480/480.
Always-open170/480; trained-frozen150/480. One-seed manager-frozen and severed-
permission controls each30/96, versus native96/96. Ten original record IDs and
their stored weights remain unchanged. Strong CPU repeat-admission also480/480;
all cold/distractor/transient queries and stronger CPU results are in the
[assessment](../studies/20261025-learned-admission/ASSESSMENT.md).

## Source map

- `model.py`, `prepare.py`, `bench.cpp`, `run.py`: first-seed fixed-policy prerequisite.
- `learned.py`: own fixed coding, native recency design, bit-set learning replay,
  sealed workloads and independent raw-key CPU dictionaries.
- `prepare_learned.py`: virtual/compiler-only preparation; no physical-device
  discovery or opening. `prepare.py:bind` preserves compiler routes and restores
  each intermediate learner's modes and own initialized records.
- `learned_bench.cpp`: packed C++ reference and native instrument; captures every
  output, descriptor, input and all three RAMs. Teacher pointers consume the
  native query output; no semantic permission branch exists in the host actor.
- `learned_run.py`: finite authority, source/fixture freeze, staged admission,
  device-free check, exclusive lock, owned watchdog and saved-array verification.
- `archive.py`, `mutations.py`: public numeric-only audit and corruption checks.
- `visual.py`, `video_qa.py`: source-bound4K60 replay and decoded-frame checks.
- `relevance.py`: software-only counterexamples for the repetition heuristic,
  preserving all intermediate arrays and keeping physical evidence counts separate.

program images and the licensed SDK/runtime are not distributed. Physical
admissions additionally need a new prospective study, finite AUTHORITY/STATE,
free device, lock and qualified predecessor gates. The published studies are
closed; do not reopen their authority to launch another experiment.

targets macOS VideoToolbox. Rendered connections/returned bits come from measured

## Native prediction error and contradiction revision

`error.py`, `prepare_error.py`, `error_bench.cpp`, `error_run.py` build and
qualify the five-group native error comparator. It passes stationary learning
but fails reversal and capacity; [negative assessment](../studies/20261025-prediction-error/ASSESSMENT.md).

`recycle.py`, `prepare_recycle.py`, `recycle_bench.cpp`, `recycle_run.py` add a
prospectively frozen common/key representation and native negative-evidence role.
The host supplies actual/complement labels on fixed clocks; it never chooses an
error, record, threshold reset or weight repair. `build_error.sh` and
`build_recycle.sh` require the same separately licensed environment described above.
Both studies are closed and need a fresh bounded authority to run more hardware.

`correction_archive.py` packages/replays both studies' numeric captures;
`correction_mutations.py` rejects six semantically corrupted captures even when
hash validation is bypassed. `correction_visual.py` derives the continuous
recorded replay from that audited archive. [Results and limits](../studies/20261025-native-correction/ASSESSMENT.md).


## Independent memories and native learned-source transfer

`isolation.py`, `prepare_isolation.py`, `isolation_bench.cpp`, `isolation_run.py`,
`build_isolation.sh` qualify two correcting banks with identical teacher clocks.
Native context routing supplies disjoint plastic feature support; every foreign
boundary is checked. `isolation_archive.py`, `isolation_mutations.py` and
`isolation_visual.py` package the31-session/31,500-forward evidence and preserve
its failed overloaded-bank capacity gate. [Assessment](../studies/20261025-isolated-correction/ASSESSMENT.md).

`transfer.py`, `prepare_transfer.py`, `transfer_bench.cpp`, `transfer_run.py` and
`build_transfer.sh` qualify a learned source teaching two valence-specific native
student banks. Both student clocks stay enabled during transfer, with constant
class0 descriptors and no host-provided outcome. All banks use two hardware
classes, but student plastic records occupy class0 only. Teacher-silent exams mask
source plastic cue coding while fixed key helpers still run. `transfer_archive.py`
and `transfer_mutations.py` replay12 qualified sessions/2,754 forwards and preserve
one62-forward failed actor prefix, with no silent retry. `transfer_visual.py` binds
recorded edges and responses to a continuous schematic3D replay.
[Assessment](../studies/20261025-native-transfer/ASSESSMENT.md).

```sh
python -m admission.isolation_archive audit
python -m admission.isolation_mutations
python -m admission.transfer_archive audit
python -m admission.transfer_mutations
python -m admission.transfer_visual --out NEW_OUTPUT_FOLDER --video
python -m admission.correction_video_qa NEW_OUTPUT_FOLDER --pattern 'native-teacher-transfer-*.mp4'
```

Both studies are closed; fresh physical execution requires a new finite prospective
authority and qualified predecessor gates. Both strong CPU functional controls pass.
Source-mode journals are not electrical bus traces. No native advantage in speed,
energy, concurrency, general eviction or autonomous scheduling follows from these
functional qualifications. The transfer record-level source-teacher responses are
derived; student bits, stored RAM and native output payloads are read back.


## Repeated correction propagated between learned groups

`revision.py`, `prepare_revision.py`, `revision_bench.cpp`, `revision_run.py` and
`build_revision.sh` extend the native transfer mechanism with fixed external
source-negative evidence roles. All controls first learn the same prefix; freezing
students or cutting teaching occurs only afterwards. Source retirement is separately
ablated. Native transfer class remains zero and both students share the same clock.

`revision_archive.py` verifies every packet and complete three-bank RAM boundary,
common trained prefixes, source-trajectory equality under cut/frozen students and
full unrelated record payload retention. Useful native failures stop expansion
separately from execution failures; negative controls remain execution passes.
`revision_mutations.py` tests semantic rejection beyond matching hashes.
`revision_visual.py` reuses the source-bound3D connection scene and labels old answers,
source-negative evidence, native transfer and independent corrected recall.

```sh
python -m admission.revision_archive audit
python -m admission.revision_mutations
python -m admission.revision_visual --out NEW_OUTPUT_FOLDER --video
python -m admission.correction_video_qa NEW_OUTPUT_FOLDER --pattern 'native-memory-revision-*.mp4'
```

four cue associations across24 plastic records/seven sequential FNP3s. CPU functional
controls also pass. No whole-chip utilization, electrical concurrency, general
memory eviction, autonomous truth checking or calibrated speed/energy gain follows.
