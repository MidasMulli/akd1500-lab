# Bounded native feedback

An AKD output becomes the next input by a direct device-SRAM address dependency.
Native learning sharpens four seeded associations during a 32-step quiet-worker
run. A fixed second FNP3 relays the binary output. The finite schedule is
prepared beforehand; this is not indefinite self-scheduling or a CPU advantage.

The portable audit needs NumPy. The recorded renderer adds Pillow/FFmpeg and
uses the existing source-bound neuron renderer. Hardware preparation uses the
separately supplied Akida 2.19.3 SDK. `prepare.py` only maps virtual hardware;
it never discovers physical devices. The build needs AKIDA_ENGINE_ROOT,
AKIDA_RUNTIME_LIBRARY and FLATBUFFERS_INCLUDE. `run.py` preserves the original
sequential gates, locks, source freeze and finite budgets. The saved study is
closed; arrange a separate prospectively authorized study for new admissions.

The film's neural geometry is schematic. Returned binary outputs are measured;
connection snapshots come from separate exact-state prefix recordings. The
device's electrical spike timing and physical neuron locations are unobserved.
