# Repeated learning in one resident native feedback session

The same two-NPU graph alternates between observing fresh synthetic outcomes,
updating native connections, probing recall and continuing from its last output
in device SRAM. It is programmed once. There are no weight restores or threshold
resets during a run. The host paces these phases and supplies external examples.

Across five initializations and twelve map changes per resident run:

| Endpoint | Native0.75 | Inherited0.25 | Frozen | Unlabelled |
| --- | ---: | ---: | ---: | ---: |
| Changed-rule checks | 120/120 | 60/120 | 60/120 | 60/120 |
| Unchanged-association checks | 360/360 | 360/360 | 360/360 | 360/360 |
| Post-update feedback consistency | 960/960 | 888/960 | 840/960 | 840/960 |
| Cumulative connection replacements | 1,920 | 160 | 0 | 0 |

The stronger source-keyed CPU table also passes. No speed/energy advantage or
unprecedented algorithm is established: the hardware learning rule and competition
setting are existing SDK mechanisms. The new qualification is repeated adaptation
and state carry in this bounded resident experiment.

## A query can affect later learning without changing visible learning RAM

The initial CPU model failed at a partial connection replacement. Advancing the
reconstructed score accumulator during unlabelled prediction, rather than only
labelled teaching, predicts the saved failure and fresh suffixes/initializations.
The failed physical prefix and25 superseded CPU forecasts are preserved separately.

An additional one-initialization control compares0,1 and8 incomplete queries, and
8 full queries, before the same next teaching event. Complete visible learning RAM
is identical immediately before that event. The eight-query cases have identical
descriptor counts and returned codes. Eight incomplete cues change six subsequent
mask bits relative to zero queries; eight full cues do not. One incomplete cue also
does not change the selected mask in this case. The eight-incomplete case repeats
exactly. No hidden register was directly read, and no unique microarchitectural
implementation or persistence across reset is established.

## Boundaries

Eight class-addressed records, one prototype/class, engineered initial cycle,
two alternating synthetic maps. The twelve changes revisit two maps, rather than
teaching twelve unrelated worlds. Native updates receive external destination
labels from an independent context-observation stream; they are not automatically
generated by the chip or necessarily outcomes of the carried trajectory itself.
The host pauses feedback to insert teaching and probes. Its saved last native output
is retained across those operations and feeds the next burst without reseeding.

The film shows measured returned codes and selected-connection SRAM. Intermediate
quiet-burst weights are not directly probed; boundary readbacks agree and those
descriptors have no teaching labels. Class activity is inferred through the fixed
decoder. Geometry, flow particles, camera and slowed timing are schematic, with no
electrical spike tracing. No indefinite autonomous scheduling, real-world robot
control, CPU advantage or resolution of the older FNP2/multi-pass failures is claimed.
