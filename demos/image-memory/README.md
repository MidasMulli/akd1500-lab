# Native silhouette memory

Recorded chip replay. From the repository root, run `python -m http.server 8000 --bind 127.0.0.1` and open `http://127.0.0.1:8000/demos/image-memory/`.

The existing renderer and captured data are preserved. Geometry/timing are schematic; response bits and RAM changes are measured. World-model scene images are deterministic reconstructions, not camera footage or AKD-generated images. Detailed claims, controls and failed gates are in [current status](../../docs/STATUS.md). MP4s and numeric packages are in [downloads](../../docs/REPRODUCING.md).
