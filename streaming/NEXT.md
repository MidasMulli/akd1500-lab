# Next gates after the failed streaming pilot

The current study is closed. Do not enable skipping, add seeds, lower thresholds,
change target bands or replace the model inside its saved protocol.

1. **Qualify the useful Nano query first.** T202's coarse band accuracy on this
   command stream is weak. Select a supported model/regime and a concrete bounded
   downstream question, then validate its quality against actual observations.
   Avoid presenting a band predictor as a replacement for full RGB imagination.
2. **Fix workload coverage prospectively.** The first baseline stream contains no
   band-1 outcomes. Use a separate calibration population to establish stream and
   target coverage, freeze it before reading new learner/control results, and
   evaluate on different scene/action draws. Preserve this failed pilot.
3. **Resolve native prediction quality before scaling.** Learning beats frozen
   here but trails the effective CPU control. Diagnose representation, record
   recruitment and confidence using a bounded CPU/reference study, with named
   candidates and stop rules. More NPUs do not by themselves repair this gap.
4. **Validate confidence on fresh data.** The current fixed rule makes one error
   among 35 eligible queries. It fails its 2% limit. Do not tune a confidence
   threshold on those same cases and call it held-out reliability.
5. **Only then admit actual skipped forecasts.** Compare forced-model, native
   gating and CPU gating on identical streams. Count input extraction, state
   catch-up, model refreshes and every error. Cheap AKD inputs must not require
   the model computation being claimed as avoided. Match the required output:
   a coarse band is not the full model's RGB/event/planning contract.

The present data supports a native-adaptation research update. It does not meet
the promised practical-advantage post gate. Any new physical study needs a fresh
prospective protocol and bounded admission; no current job remains running.
