# Recovery through bounded exploration

New study; all earlier studies remain closed. User: "Agree, go" after the
proposal to finish failure/recovery, then prepare a Mario temporal-learning test.

One chip, three fixed action encodings (71011/12/13). Six NPUs: two plastic
memories, fixed encoders, fixed decision and commit. The new host input is one
probe-request bit at input byte20, admitted only between queues. The fixed
native decision circuit selects the opposite of its last action in the current
task state. The host never writes an action, prediction or learned connection.
This is supplied exploration, not learned exploration or general reinforcement
learning. Query/teacher separation and all fixed/protected memory checks remain.

24 offered real JPEG jobs; 80 total operations and eight per job. Warm-up jobs
0..7 alternate normal/probe requests, shared by every arm. Then preferred
decode backend is stopped for jobs8..11; both backends run12..19; the alternate
backend is stopped20..23. Only owned test workers are signalled. Acting input
contains task/action/outcome codes, never the availability schedule. After
warm-up, probe only at the first source-state action of every fourth job, with
fixed offsets0/1/2 for the three encodings. Probe costs and timeouts count.

Arms: native probe, native reactive (probe clock off after common warm-up),
native probe with transition learning frozen after warm-up, identical CPU probe.
All use the same neural fixtures/initial memories and real image operators.
Actual PNGs, source/output bytes and native MMIO/RAM are independently audited.
The three encodings vary labels and probe alignment, not physical chips or
independent environments. No electrical advantage is inferred.

Stages: virtual exhaustive probe and non-probe algebra; physical 8-cycle
mechanism with query isolation; two real JPEG smoke; one full native pilot
and raw review; only then remaining encodings/controls. Maximum18 native
sessions,150000 forwards,180s each,120min total with two-minute closeout margin.
Stop on device ownership, raw audit, image fidelity, cleanup, clock or unexplained
native/CPU mismatch. Preserve every failure; source amendments get a new frozen
namespace rather than changing a physically executed study.

Endpoints frozen before physical results: (1) exact native mechanics/zero query
learning; (2) the preferred source transition previously observed failed is
queried and corrected by job15 in each probe arm, with no such recovery query in
reactive jobs12..19; (3) all24 valid PNGs in probe arms, more completions than
frozen controls; (4) probe versus reactive net operations are noninferior within
two extra attempts per encoding, including probes; (5) identical CPU action and
outcome sequence. A gate pass permits a first bounded Mario interface/skill
pilot, not a full-game learning or AKD substrate advantage claim. If operational
utility fails, preserve the distinction between recovery knowledge and value.
