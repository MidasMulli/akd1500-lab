## Native mechanism and what this tests

Seven sequential FNP3 groups host two plastic banks. Bank A has 64 used records
(8 plastic, 56 fixed helpers); bank B has 32 (8 plastic, 24 helpers). Each record
has exactly 32 binary connections. Both banks use the qualified shared/key coding
and prediction-error positive/negative teaching rule. The two contexts use the
same four cue IDs with initially opposite actual outcomes. Keys 0/1 change rules
in one context at a time; keys 2/3 stay stable in both contexts.

Both native banks are enabled on every teacher, independent of raw context. The
fixed native feature route supplies a matching code to the selected bank, and
foreign forwarding fields that do not overlap the other bank's plastic support.
No host bank selection or context-dependent mode clock is permitted in the native
arm. Fixed helpers relay the second context through bank A and the first bank's
responses through bank B. This qualifies resident communication and functional
isolation, not simultaneous electrical execution or a global activity trace.

The host writes only raw context, raw cue, actual/complement class metadata, and
fixed query/positive/negative phase clocks. Both teacher roles consume the saved
pre-update native query-output pointer. Query context bytes 24–27 and key bytes
32–63 may be overwritten; actual/phase bytes 64–71 cannot overwrite saved native
prediction flags 84–85. No host admission bit, record choice, weight repair or
threshold reset. Synthetic prediction writes are confined to truth-table tests.

   Then matched no-retirement and trained-frozen controls; their accuracy may be

   by 96 balanced probes (48/context). First native must pass 1152/1152 with no
   ambiguity/missing outputs and preserve four unrelated records completely.
   Then no-retirement/frozen controls. Only after these pass semantic checks,
   admit seeds 114201/114301 on the same base stream with the same controls.
4. First initialization on held-out stream seeds 117101,117201,117301: shuffled
   bootstrap/training/query orders, same role/observation counts. Native must
   pass before its two controls; no adaptive selection or dropped failed seeds.
5. First-seed/base-stream solo A, solo B (same resident binary, other context's
   observations removed), freeze-A and freeze-B after bootstrap. Compare the
   native visible per-context RAM trajectories to the filtered solo trajectories.
   A difference is a result, not an execution failure. This cannot establish
   independence of unobserved selector registers or electrical activity.
