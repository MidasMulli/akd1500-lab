# Compiler-routed resident native-learning network

Direct authorization: "Go build" following the resident-learner, host-offload
and real-image-work plan. The installed mapping definition exposes seven FNP3
placements and one FNP2 placement, not 32 independently supported FNP3 banks.
The eighth physical bank is outside this FNP3-only instrument's admission.

Prior separately compiled same-column contexts had indistinguishable ingress
routes. Do not retry that construction or guess NNID/register changes. Build
one compiler-routed sequential graph with 2, 4 and then 7 native FNP3 learning
banks. This tests several connected plastic stages, not independent simultaneous
input streams. All use the same externally supplied class label for an event.

Each bank has 512 binary inputs, 64 configured neurons, 32 selected connections
per neuron and two class groups. Between banks a fixed dual-rail encoder maps
each response to four positive or four complementary feature bits, keeping
exactly 256 of 512 features active. Threshold response is potential > 15.
A final fixed layer returns two group-support counts. The encoders and reducer
are supplied by us. Local native updates do not imply gradient backpropagation.

Before hardware: integer forward checks against the virtual SDK, committed
placement map, single-pass-only/FNP3-only codec checks, unchanged compiler routing
tracks, preserved initial connection arrays, and reviewed mode packet indices.
Every bank's learning/inference modes and RAM are captured from its own compiled
prefix and rebound to the final compiler routing. No post-start weight writes.

Hardware ladder: 2-bank 16-event smoke, independent recount; 4-bank smoke only
after that passes; 7-bank smoke only after four banks pass. Then three seeds of
64-event confirmation at the highest admitted size, with all-learning,
one-bank-frozen and all-frozen controls. Maximum 18 physical sessions, 20,000
forwards and 180 seconds per process. Local AUTHORITY.json sets absolute clocks.
Stop expansion on unexplained output, register, RAM or fixed-encoder mismatch.

C++ population-count references and an independent Python integer/set selector
must reconstruct each bank's updates. Compare every bank RAM snapshot after
every event and actual final output counts; intermediate activations are
reconstructed unless separately captured. Fixed encoder/reducer memory is
read back initially and finally. A frozen bank's complete RAM must stay fixed.

Report caller CPU, latency and transient bookkeeping separately from native
learning. These are bounded host-supported streams. There is no restart/power
durability, chip-wide peak utilization, application accuracy or electrical
efficiency claim from this mechanism test. Preserve failures and mapping gaps.
