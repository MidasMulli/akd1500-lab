# Repeated adaptation during a resident, host-paced native feedback loop

Prospective study. Five fixed seeds111101,111201,111301,111401,111501. Eight binary FNP3 records, one destination class per record, engineered old cycle, fixed second FNP3 decoder. State code:16 shared+16 unique features in256 channels; incomplete cue removes four unique features. Same representation as the previous study, independently permuted initializations. No reload/restore/reset or host-computed weights after installation.

Primary native arm changes only fixed SDK learning_competition from0.25 to0.75, predicting an adaptive threshold cap8 rather than24. Initial threshold15,32 connections, initial plasticity0.5, minimum0.25, decay0.125 are unchanged. Inherited0.25 baseline is a separate positive-learning control; frozen and teacher-disconnected arms use0.75. Parameters stay fixed during each entire physical session. One-time frozen switch follows the initial old examples/queries.

Sixteen initial events: eight old examples, eight partial-cue queries. Each change epoch: one pre-feedback prediction from the previous native output (only the very first uses an external seed); four fresh examples (two changed contexts twice, labels from the current synthetic environment); eight matched partial-cue queries; sixteen output-to-input feedback steps. Environment alternates two permutations by swapping the same destinations. Twelve changes target one resident model. Teacher observations come from an independent external stream; no discovery of unseen states is claimed. Feedback is paced/paused by the host to insert observations and audits; updates are not claimed simultaneous with inference or indefinitely self-scheduled.

The pre-feedback output stays in device SRAM across teaching/query jobs and becomes the next feedback input. Only its address is carried by the host. Batch64 must preserve that output for fewer than64 intervening events. Every feedback input pointer must reference a previous native output+32, never a host-written state. Record readback inputs, outputs, descriptors and full learning SRAM at every serial event and each quiet-burst boundary, with fixed decoder before/after. Explicitly distinguish captured boundaries from unobserved intermediate burst states. Zero teaching labels during the16-step prediction burst; one release write and zero driver reads over a5ms sleeping control-worker interval; completion required at first wake. Other host activity is unclaimed.

Gates: compiler/scalar and packed CPU first. Primary seed111101: inherited baseline e1→e2, then native e1→e2→e4→e12. The inherited setting is expected to stall on reversal; correctly executed predicted failure is a scientific negative rather than instrument failure. Native must recall2/2 changes and retain6/6 other associations after every epoch. Then frozen/disconnected e12, then remaining four seeds all four arms e12. Inspect each saved stage before expansion. Strong source-keyed CPU table uses the same information and evaluates matched recall and predictive consistency; its intermediate teaching response need not equal destination-keyed native memory.

Exact visible-state scalar/packed replay gates all observed boundaries. A mismatch stops expansion and preserves the attempt; no hidden-state hypothesis is promoted from final accuracy. If a partial replacement reveals unresolved selector state, diagnose saved traces before any source amendment or different candidate. No competition/threshold/decay reset is permitted within a session.
