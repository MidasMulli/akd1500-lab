# Three connected native learning memories, selectively repaired

Closed October 23, 2026 Central. Ten physical sessions completed **6,672 forwards
and 20,016 complete learning-bank RAM captures**. Every output and complete state
matches an independent numerical reconstruction. All fixed parameter RAM remains
unchanged. No owned jobs remain; the device is released.

The compiler maps six FNP3 resources in one resident pass: recognition at
`(1,3,0)`, fixed class-presence encoder `(2,1,0)`, mapping memory 1 `(2,2,0)`,
fixed encoder `(2,3,0)`, mapping memory 2 `(3,1,0)`, fixed count readout `(3,2,0)`.
Each plastic bank has 512 binary inputs and 512 allocated neuron records, with
32 selected connections per record and threshold 27. Each fixed encoder ORs
within four class groups and repeats each presence bit 128 times. Multiple
groups can be present: this is neither an exclusive argmax code nor search.

The synthetic task uses four noisy beacon signatures and two learned class
permutations. The host supplies sensory events, teachers and learning-mode
changes. All intermediate neural processing stays on the device. After initial
teaching, beacon signatures change; only recognition is allowed to learn them.

Width-64, 256 and 512 mechanics smokes passed before the full first-seed
repair/frozen/wrong-bank comparison. Only then were the two reserved native
initializations admitted. These are three initializations of **one sensory
world**, not three independently sampled environments. CPU forecasts were
screened before hardware; the table contains actual native outcomes.

Complete RAM reveals how recognition preserved its earlier memories. In each
initialization, four records changed connections during original teaching, and
four different records changed during repair. Every one of the original four
records' 20 words stayed identical throughout all subsequent events. The native
rule selected the winning records and connections; the host did not choose
those record addresses or upload repaired weights. These are additional uses of
existing records, not physical neuron growth. Across the whole run, connection
edits touched **8/512 recognition records and 4/512 in each mapping memory**.
The 1,536 allocated records must not be described as 1,536 learned memories.

Recognition repair produced 89, 90 and 82 connection-edit events in the three
initializations, inserting 173, 174 and 158 connection bits respectively. Both
downstream memories retained their complete captured state during repair.
The wrong-bank arm scored 16/64 on changed signals and 64/64 on old signals, but
received **zero eligible connection updates**: its upstream changed codes were
unrecognized. It is not a matched-plastic-work intervention. Frozen controls
are the primary learning comparison.

This FNP-only architecture is an explicit alternative to the failed mixed
FNP-to-CNP graph. It does not repair or qualify that handoff. It adds a third
resident plastic population and directly verifies selective record recruitment;
it establishes neither all-32-NPU plasticity nor a silicon capacity maximum.
There is no autonomous teacher selection, recurrent planner, electrical spike
trace, power-loss durability or demonstrated CPU/energy advantage. Descriptive
host timing is unsuitable for a speed claim: diagnostics are heavy and later
trace transfers overlap confirmation activity.

One frozen invocation was rejected by the exclusive lock while the preceding
owned run was still auditing. It made no native forwards. That operational
attempt is preserved separately; the admitted arm ran after release.

The public archive stores lossless changed-word deltas of **every complete RAM
capture**, plus the SHA256 of each original full snapshot. The auditor expands
and checks every snapshot before independent learning-rule/output verification.
Programs and proprietary runtime remain external.
