# Coupled native learning resources: four teaching masks

Direct operator "Go" on the proposed sparse-work/resource-sharing/CPU sequence.
This separate study reuses the previously verified five-NPU signal-relay graph
and three compiler fixtures (seeds97101/97102/97103). No remapping or new routes.
Two plastic populations are linked by fixed native categorical communication.

Replay the exact512-event recognition/routing training prefix from the signal
relay study in every arm. No RAM-only restore. Then128 noisy old-domain samples,
four identities cycling, RNG98301. Shared identity teacher labels and learning
masks00/01/10/11. End with16 query-only samples. This is a mechanism experiment:
the shared teacher is not independently addressed teachers, and the second
bank's old destination mapping may change. Do not call it a task improvement.

Before physical admission, independently simulate all four arms for each seed.
Require the internal categorical input reaching bankB to match across all masks.
Require A state in01 to match A in11, and B state in10 to match B in11, at every
test event. Frozen banks must remain unchanged. If the input/message equality
gate fails, stop and redesign prospectively rather than attribute differences
to hardware interference under unequal inputs.

First smoke seed97101, masks00 then01 then10 then11. Each smoke uses a fresh
program and the complete512-event prefix, the first16 probe events and eight
queries. Inspect every output and both complete per-step RAM captures before
the next arm. Then admit the four full arms for that seed. Compare same-bank
states across solo/mixed arms before adding seeds97102/97103. Counter controls
must pass idle, configuration and identical buffer-end register checks. The
runtime stays globally learning-enabled for all four masks; bank configuration
packets choose teaching without changing DMA monitor scope between arms.

Measure per-event DMA service, host completion/caller time and state changes.
Compare incremental teaching cost against mask00, separating same-event edits
in both banks from literal overlapping arithmetic. Feed-forward dependency and
aggregate timing cannot establish per-neuron physical simultaneity. Every RAM
state and final output must match independently coded rules. No host-supplied
intermediate activations. No electrical-efficiency claim.

Maximum16 physical sessions,12000 forwards,180 seconds per owned process. Saved
authority cutoff applies. Source/fixture/binary freeze, exclusive lock, other
device-owner check and preserved failures required. Numerical/state/control
failure halts expansion pending diagnosis; no silent retry. Queued dual-bank
teaching is not admitted by this protocol and requires a separate source gate.
