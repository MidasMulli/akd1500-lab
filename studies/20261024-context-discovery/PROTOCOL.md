# Context allocation without context labels: prospective qualification

Purpose: remove teacher-addressed context selection before adding a predictor.
This is a component gate, not a completed autonomous world model or CPU advantage.
No X post is authorized by this protocol. Earlier films remain research evidence.

The fixed frontend carries three previous raw binary symbols and accepts only one
current raw symbol. Four slots use eight-copy dual rail (64 of128 channels). A fixed
third-order feature basis enumerates all three-of-four bit conjunctions: 256 binary
features,32 active for every valid four-bit history. It is engineered nonlinear
preprocessing, not learned representation. A native32-record FNP3 bank starts with
seeded random32-connection records, zero learning thresholds, and one class. Every
training descriptor supplies the same label0: all32 records compete and the chip
chooses the winner. No context IDs or neuron/task selectors are sent. Competition0,
initial plasticity0.5, minimum0.25, decay0.125; output threshold27. A fixed native
shift branch and merge preserve raw history independently of learned activations.
The host writes only current-symbol channels48:64 into the preceding native output
payload; it does not reconstruct history. It schedules forwards and learning phases.
This is host-paced operation, not a free-running chip or learning with no stimulus.

Raw stream: three unlabelled zero warmup bits; one unlabelled cycle of the fixed
binary de Bruijn sequence0000100110101111; then1,2,4,or12 labelled cycles; then two
unlabelled probe cycles. No learning on probes. All16 raw four-bit histories occur.
Compare intact native learning, trained-one-cycle then frozen, always unlabelled,
and severed history during probes. Severed clears only the first48 history channels.
Seeded random connections113101,113201,113301,113401,113501; no neuron is preassigned
to a history. Exact packed CPU and an independently maintained raw-symbol dictionary
are controls. The task CPU can equal the chip; no speed/energy advantage is tested.

First compile the complete fork/merge with virtual raw-history checks. Then seed
113101: native1, native2, native4, native12, inspecting raw traces after each. Prefix
stages require exact native outputs and every learning-RAM boundary, not full recall.
At12 require sixteen distinct single-record responses on the last probe cycle,
no probe-time change to connection/learning fields, stable assignments throughout
both probe cycles after three-symbol wash-in, and changed native connections in
at least16 records. If this fails, stop dependent expansion and preserve the result.
Only after qualification run first seed's three controls, then other seeds' native,
frozen and unlabelled arms. Frozen may still learn after one cycle only if the
protocol is prospectively amended; no silent warmup extension. Each independent
session programs once; no mid-run weight/threshold repair or model reload.

Read every descriptor, returned payload, carried input, fixed-bank RAM before/after,
and full learning RAM after each event. Verify against source-derived CPU replay.
Reject source/hash drift or semantic label/history corruption even with rehashed
receipts. Physical runs need the exclusive research lock and a free device. Preserve
failed compiler/transport/scientific attempts separately. Stop only owned jobs.

Preliminary CPU-only exploration before this freeze found the unprojected dual-rail
basis aliases histories: at16 patterns only8–11 distinct response masks across five
seeds. Retain that rejected screen. The chosen explicit third-order basis passes the
same offline screen; its preprocessing cost and restricted finite history are limits.
No downstream predictor is admitted until these raw context-allocation gates pass.
