# Changed native transition memory

Prospective design: five initializations (110101,110201,110301,110401,110501), eight states, eight binary FNP3 records, eight externally supplied destination classes, one prototype/class. Each state contains 16 common anchors and 16 unique features in 256 channels. An engineered old eight-state cycle is the prior. One fixed FNP3 decoder maps the predicted class to the next state code. This is externally taught associative memory, not discovery, search or a learned representation.

In each fresh session: eight unchanged full-code examples, eight unlabelled partial-cue queries, two changed transition examples (swapped destinations), eight unlabelled partial-cue queries. Partial cues omit four of 16 state features. Native arm receives the real changed destination class, frozen arm disables learning before changed examples, disconnected arm omits the class. All inputs otherwise match. Outputs precede updates. Capture all 26 outputs and complete visible learning SRAM states, fixed decoder before/after. Native must recall both changes, preserve all six unchanged associations, and match independent scalar and packed CPU replay exactly. Controls must preserve the old function. No hidden-selector-state or power-cycle persistence claim.

Then eight independent seed cues each feed a finite dependent queue of unlabelled predictions. Input pointers after the first must point directly to the preceding output payload in device system SRAM, never a host-computed next state. Entire queue is prepared before release. Sleep the controlling worker for 5ms; require completion at first wake, zero reads and just the release write. No claim all host cores/OS are quiet. Visible learner and decoder SRAM must remain unchanged during query-only rollout.

Stages: all CPU fixtures first; seed110101 native diagnostic-only (h0), then h1, h2, h4, h32. Check raw-derived results before each admission. Then frozen and disconnected h32, then the remaining four seeds/all three arms h32. Exact CPU rule and an optimized eight-entry transition table are separate controls; report equivalence and timing without an energy or CPU-advantage claim. One native change episode only: adaptive learning threshold may prevent a later reversal. Do not silently lower thresholds.

Maximum 48 physical sessions and 8000 forwards, 30s per owned process. Any mismatch stops expansion and preserves the failed attempt. Routine repair requires an explicit saved repair receipt and a new source freeze before resuming. Deadline in AUTHORITY.json. Do not stop another owner's jobs.

Secondary gate, only after primary validation: inspect compiler/runtime hardware-generated replay; freeze a separate finite source/config test before hardware admission. Do not infer indefinite recurrence, inter-pass learning-state retention or success from register names. Keep programmed DMA sequencing separate from neural prediction and native learning.

Capture schematic replay driven by recorded outputs, native connection readbacks and queue observations. No invented electrical spike trace. Earlier FNP2 high-address learning issue remains unresolved and this small FNP3 study does not fix it.
