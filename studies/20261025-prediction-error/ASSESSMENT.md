# Native error admission works; admission alone cannot correct or reclaim

Eighteen qualified physical sessions, 2,304 native forwards. All captured inputs,
outputs, every learning-RAM boundary and fixed-group RAM checks pass independent
saved-array verification on Nano and Mac. The study is closed; device released.
The [numeric archive](../../results/20261025-native-correction.json) preserves this
family separately from its later correction revision.

The native signed fixed circuit compares saved prediction flags in query-output
SRAM with a delayed external actual outcome. It admits missing/ambiguous/wrong
predictions; it blocks correct ones. Exhaustive native/open/closed truth tables
pass all 16 cases per variant. No host correctness/admission bit is supplied.

Three initial connection seeds on the same stationary stream: held-out read-only
queries are 144/144 native, 144/144 always-open and 66/144 trained-then-frozen.
The native gate admits 24/96 teachers versus 96/96 open; cutting the saved
prediction admits all 32 teachers on the first seed. Original associations remain
correct while new ones are learned. CPU dictionary and eight-entry LRU also
pass 144/144, and acquire new facts in fewer observations.

**Admitted teachers are not connection-edit or energy savings.** Native and open
each make 347 connection replacements. Two seeds have different intermediate
swap orders, while all three finish with equal RAM. The audit rejected an
overstrong post-hoc claim of identical intermediate trajectories; the repair is
preserved in the later study's [repair receipt](../20261025-native-correction/REPAIRS.json).

The prospective boundary tests fail scientifically, as the prior software screen
forecast. After outcomes reverse, native and open each score 0/48, with all 48
predictions ambiguous: the old class association remains while its opposite is
added. Under repeated-distraction capacity pressure, each scores 27/96; no later
association is acquired. The CPU dictionary scores 96/96 and eight-entry LRU
69/96, trading away old-key retention. These are valid executions of a failed
useful-memory hypothesis, not failed hardware attempts.

No larger allocation or additional boundary seeds were admitted. The next study
changes both representation and teaching roles to test native contradiction and
bounded record reuse. It must be assessed against its own matched controls.
