# Native prediction-error admission: finite qualification

Direct user approval: Go. This is a fresh study; prior authorities stay closed.
The saved software screen precedes hardware and predicts success on stationary
learning, but failure on reversal and capacity. Those boundary cells confirm a
predicted limitation; they are not a surprise discovery or a positive gate.

## Circuit and acting boundary

Five sequential FNP3 groups, one binary plastic bank: eight competing records,
four per outcome class, each with exactly 32 connections; 24 read-only helpers.
Four fixed inference groups decode the raw key, compare a saved native prediction
to a later actual outcome, gate teaching, and relay predictions/raw keys.
The comparator uses signed 2-bit fixed weights; the plastic bank stays binary.
The objective is designed: admit a teacher when its prior prediction is missing,
ambiguous, or wrong. This is not a learned objective or general relevance rule.

Queries overwrite only the raw key (bytes 32–63) and phase word (64–67).
Teachers reuse the prior query's native output address and overwrite phase plus
the raw actual-outcome one-hot word. The actual is also the native learning class
label. Predicted class flags are in bytes 84–85, outside both writes. No host
correctness/admission decision, record choice, weight repair or per-record reset.
The host paces all forwards and switches query/teacher learning modes. Full RAM
and output captures are instrumentation; not an efficiency benchmark.

## Frozen staged cells and stop rules

1. Exhaustive fixed-state truth table: 4 predicted flag states × 2 actuals ×
   query/teacher = 16 forwards, learning disabled. Synthetic prediction writes
   are confined to this stage. Native/open/closed variants must match every bit.
2. Stationary learning: train 0/1, retain them, then learn 2/3. Forty-eight sealed
   read-only queries in one fixed shuffled ordering. First initialization native,
   then open, trained-then-frozen, and cut-prediction controls. Only after all
   byte/RAM gates pass, admit two more initializations native/open/frozen.
3. Confirm reversal on the first initialization native/open/frozen: opposite
   outcomes for known keys; 48 sealed queries. Useful adaptation requires at
   least 44/48 correct, with no ambiguous outputs and old state addressed by a
   declared native mechanism. Predicted failure prevents a reuse claim.
4. Confirm capacity on first initialization native/open/frozen: old keys 0/1,
   repeated distractions 2–7, later keys 8–11, 96 sealed queries of old+later.
   Useful memory requires at least 87/96 and retention of both old associations.
   Failure prevents more seeds, larger hardware allocation, or an app deployment.

There are at most 19 native sessions in this full list; the finite authority
permits 18, so frozen reversal is omitted unless another unused cell is removed
prospectively. Default execution: all ten stationary cells, three truth cells,
native/open reversal and native/open/frozen capacity = 18. No automatic retries.
Any execution/raw semantic mismatch fails closed and preserves all prefixes.
A scientific negative is preserved as a negative and is distinct from an
execution failure. No expansion beyond these boundary confirmations on a negative.

## Controls, gates and interpretation

Open admits every teacher. Closed blocks all teachers. Frozen learns the same
bootstrap then disables updates. Cut zeros the saved predicted flags on teachers,
which should make every prediction appear missing and reopen admission.
Queries must never change learning RAM; refused teachers must leave it unchanged;
all helper records and four fixed group RAMs must remain byte-identical.
Native outputs and every plastic RAM boundary must equal an independently
executed bit-set Python reference and the separate packed C++ replay.
Each real teacher must use the preceding native query output pointer directly.

Strong task controls: an unbounded latest-observation dictionary and eight-entry
LRU with the same raw keys/outcomes; no future-use signal. Report their complete
query accuracy, including faster one-observation acquisition. Capacity is matched
in entries only, not bytes or energy. No CPU superiority claim. Three initial
connection seeds share one fixed stream and query ordering, not three worlds.

Only raw-derived measured changes may drive visuals. Geometry/flow is schematic;
frame timing is replay timing, not spike timing. Preserve failures and distinguish
positive mechanism qualification from useful retention/reversal qualification.
