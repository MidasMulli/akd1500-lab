# Matched learning with compact threshold readout

Direct user authorization: "Press on" after the measured mesh/public-tooling
release and the proposed reduced-readback and calibrated-power next stage.
This is a new bounded study; the previous 24-session study stays closed.

## Frozen question and gates

Compare the same binary association learner with integer-potential output and
one-bit activated output. Inputs, labels, 32 selected connections per neuron,
initial weights and learning parameters are identical. Activation uses a fixed
output threshold of seven, separate from the adaptive learning threshold.
The compact contract is every neuron's threshold response, not class argmax,
image recognition or an application-level decision.

Each potential must match an independent CPU population count; each compact
response must equal potential > 7. Full final learning RAM must equal the
independent selector/update model in every passing run. Across output contracts,
all learned connection and adaptive-threshold words must remain identical.
Fixed activation-format fields may differ and are enumerated before execution.
An unexplained output or learning mismatch stops expansion.

Stage 1: compiler-only paired 128/8, 512/64 and 512/512 fixtures. Inspect virtual
outputs, FNP3 records, single-pass dense formats, fixed-field differences and
committed NPU placements. No hardware discovery during fixture generation.
Stage 2: 16-sample serial smoke of both contracts at 128/8; independently recount.
Stage 3: 64-sample paired 512/512 pilot; independently recount.
Stage 4: only after those pass, three interleaved 256-sample timing replicates
per contract in serial and resident-eight modes, using nine descriptor slots.
Stage 5: at most two 64-sample inference-only controls, requiring unchanged RAM.
Maximum 18 physical programming sessions and 50,000 forwards. Per-process cap
180 seconds; absolute cutoff and cleanup clock are in local AUTHORITY.json.

Report host input, submission, fetch, resident output drain, complete transaction
time, MMIO call/byte counts and host thread CPU time. Exclude compilation,
programming, independent verification, disk I/O and memory snapshots from timing.
CPU timing uses the same output contract, optimized popcounts and amortized fresh
streams. Add an inference-only early-exit threshold reference where appropriate;
do not present a full-score CPU baseline as the fastest threshold algorithm.
One chip and temporal repeats do not establish population performance.

## Boundaries

No clock, voltage, firmware, installed driver/SDK or unrelated-service changes.
Use the shared device lock, preserve every failure and clean up only owned jobs.
No claim of peak utilization, novel activation hardware, neural classification
accuracy, or application utility from this synthetic learning kernel.
No electrical energy ratio without a separately connected, calibrated sensor.
Present reduced readback and CPU competitiveness as separate findings.
Package own tooling and sanitized raw evidence; no licensed runtime sources.
