## Engineered mechanism and host boundary

grounded two-class cohorts, eight plastic records/class), two student valence
banks (eight plastic records each), and four fixed encoding/routing stages.
External facts train cohort A or B using positive and complementary negative
examples. Only the corresponding 32-record class partition may change per source
learning role. A fixed native comparison requires the two learned sources to give
the same unique answer before generating student teaching features. The native
learning algorithm chooses records and changes connections; no host weight edits.

Student transfer uses class zero, no actual-outcome input bytes, identical student
mode clocks, and direct card-SRAM query carry pointers. Host writes raw keys and
fixed phase roles only. Fixed query carriers expose four source class flags and
student responses at the final output. Teacher-silent student exams mask the source
plastic cue code, while fixed key relays and the source NPU remain clocked.

The agreement predicate is qualified for at most one responding record per source
class. Every captured query and transfer checks that bound; violation stops useful
admission. Duplicate-match robustness is not claimed. Agreement cannot establish
truth when both sources receive the same false fact; test that failure explicitly.
