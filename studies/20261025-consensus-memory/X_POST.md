Memory that can refuse an update

Two learned groups on my AKD1500 now control whether other memories are updated. Disagreement holds those connections; corroborated changes let the chip revise them natively.

Swapping which source was wrong: native recall 288/288; CPU policies always trusting A or B, 216/288 each. A controlled four-cue, 18-cycle test passed 864/864 protected recall and 864/864 after legitimate updates.

When both sources were wrong, it learned the error.

Host-paced, designed agreement rule. Recorded chip replay; schematic 3D. CPU agreement also passes.
