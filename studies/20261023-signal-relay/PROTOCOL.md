# Independently taught recognition and routing in one resident graph

User authorized: "think deep and let's connect the threads, if there's another
game or application that would test the chips unique hardware let's pursue it".
This new bounded study does not resume any closed experiment.

Two native learning banks implement different functions. Recognition learns
four noisy sensor identities. A fixed native pairwise comparator and categorical
encoder send a 128-of-512 identity message to the routing bank. Routing learns a
separately sampled identity-to-destination association. A fixed native reducer
returns four support counts. The host never supplies intermediate activations.

Training is isolated by separately enabling each bank with its own teacher.
Recognition sees identity labels; routing sees destination labels. All arms
replay the same recognition and routing prefix from a fresh program. No restore
of only visible learning RAM is used. Input features contain no identity,
destination, domain marker or teaching label.

After the sensor signatures change, compare recognition-only repair, frozen,
and routing-only repair. Teach recognition with identity labels and routing
with destination labels. Probes disable learning on both banks. Require >=85%
old and changed accuracy, >=30 percentage-point gain over frozen, >=80% old
retention, and completely unchanged downstream learning RAM during recognition
repair. These are synthetic development gates, not application qualification.

Order: source/dataset freeze; CPU forecast; compiler virtual inference and
single-pass FNP3 mapping; mixed 64-event physical smoke with independent every-
step RAM verification; first seed complete matched arms and independent recount;
only then the remaining two seeds. Stop on unexplained native/reference mismatch
or failed first-seed task gate. Preserve every failed compilation and session.
Native sessions remain bounded by AUTHORITY.json, 180 seconds each, 12 sessions,
and at most 15,000 forwards. Release only owned jobs and close admissions.

All intermediate response displays must be labeled reconstructed. Captured RAM,
final destination support and timing come from hardware. RAM snapshots and
diagnostic reconstruction are excluded from any future throughput comparison.
No energy or optimized-CPU advantage follows from mechanism/function results.
