# Native plastic manager controlling consequence memory

Prospective continuation of the user's approved native memory-controller goal.
The fixed-policy qualification is closed at seven hardware sessions; its one-seed
results and failed attempts remain separate. Do not rebrand it as the present
three-bank circuit or as a five-seed result.

Target: three resident plastic groups across seven sequential FNP3s. A native
manager record learns the latest raw key in its synapses. Its returned pre-update
match permits teaching a separate protected consequence bank. An always-updating
bank receives the same actual outcomes. The Nano supplies raw observations,
uniform query/teacher clocks and actual consequences, never context IDs, bank
choices, neuron IDs, recency calculations or weight repairs.

## Designed versus learned

The repeat-admission rule and coding are designed. A manager record has25 common
connections plus7 variable key connections. Constant common activity keeps its
native learning score above the frozen competition ceiling24. Native swaps can
then replace the seven variable connections in one observation. It responds only
when all32 connections match, before it learns the current key. This is a custom
use of BrainChip's existing native rule as synaptic recency state; it is not a new
silicon instruction, learned utility objective, unconstrained emergence or proof
that CPUs cannot perform the task. The manager is a one-record mechanism, not a
claim of complex cognition. Single-class learning and helper records are existing
primitives. Resident coordination of three plastic groups and native synaptic
control of selective memory admission are the experimental contribution.

## Acting path and evidence

Raw observation -> fixed binary coding -> native plastic manager -> fixed gate ->
always-update bank with fixed forwarding helpers -> native bridge -> protected
bank -> fixed prediction/raw-key/permission output. Seven FNP3s, four fixed layers,
three learning banks. No per-observation program reload or host-selected record.
The previous-key input field is disconnected from the encoder: acting recency
comes from manager RAM. Query labels are always0 for its single class. Both
consequence banks are inference-only during queries. Their binary outcome
predictions must return before teacher labels are submitted.

The teacher reads the just-returned native query output by pointer, containing
the raw key and returned manager permission. Nano changes the uniform phase word
and supplies the actual binary outcome; it must not inspect the permission to
decide any acting command. Manager is disabled during teachers, both consequence
banks enabled. Per-bank clocks follow this fixed two-phase schedule and control
arm only. This is host-paced, not independently self-scheduling operation.

During held-out no-outcome recall, consequence RAM must stay unchanged while
manager RAM continues tracking raw observations. Do not call the entire chip
read-only or treat native manager updates as additional outcome supervision.
