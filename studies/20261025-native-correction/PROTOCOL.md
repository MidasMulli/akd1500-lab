# Native contradiction and bounded record reuse

This is a new finite study after the closed error-only experiment failed reversal
and capacity. No prior authority is reopened. Its software screen forecasts that
a designed negative-evidence feature can retire the obsolete association. Freeze
this circuit and stream before the first physical cell.

## Changed mechanism

Same five sequential FNP3 groups and one eight-plastic-record bank, with 24 fixed
helpers. Each plastic neuron keeps exactly 32 binary connections. A record starts
with 25 shared connections and seven variable key connections. The shared input
keeps a matching record eligible under the native competition threshold; it is a
designed representation, not discovered structure or a new silicon algorithm.

A query is followed by two fixed teacher roles after an external outcome arrives:
positive evidence targets the actual class; negative evidence targets its logical
complement. Both roles compare the *same saved pre-update native query prediction*
to the actual, in the native fixed circuit. Correct predictions block both roles.
The negative role presents six key features plus one retirement sentinel, instead
of seven key features. Native learning selects the matching competing record and
can swap its seventh key connection to the sentinel. A later ordinary query has
no sentinel, so that obsolete class response stops firing at threshold 31.

The host supplies raw key, actual outcome and predetermined query/positive/negative
phase clocks. Class labels are actual/complement-of-actual facts, never a decoded
chip error. It never chooses a neuron, writes a learned weight, resets a threshold
or uses a host-computed admission decision. Teachers reuse native query-output
SRAM directly. Phase bytes 64–71 cannot overwrite saved prediction bytes 84–85.
This is host-paced negative teaching, not autonomous self-discovery or unlearning
without contradictory evidence. The objective and retirement representation are
engineered. Four known key identities, two outcomes; no arbitrary-image claim.

## Stages and gates

1. Native/open/closed exhaustive comparator: four saved-prediction flag states ×
   two actuals × query/positive/negative phases = 24 fixed-state forwards. All
   synthetic prediction writes confined to these truth-table cells.
2. First initialization correction: bootstrap four associations, then reverse
   outcomes for keys 0/1 while keys 2/3 remain stable. Native must pass 48/48 sealed
   read-only queries with no ambiguity and preserve the unrelated original
   connection vectors exactly. Then admit matched no-retirement, frozen and
   severed-prediction controls; each must match its exact predeclared replay.
   No-retirement may pass this first reversal; it must not be represented as
   necessarily failing. The software screen already shows this seed sensitivity.
3. After all stage-2 execution/semantic gates pass, run 12 alternating reversals
   with 48 read-only probes after each. First initialization native must pass
   576/576, keep two unrelated original vectors unchanged, and use the same eight
   physical records without resets or program reloads. Then matched no-retirement
   and frozen controls. After these, admit two more native/control initializations
   on the exact same stream/order. Three initial connection seeds, not three worlds.

Any raw/semantic mismatch stops execution, preserving prefixes; no automatic retry.
Any native accuracy/retention failure stops expansion. A control's scientific
negative is preserved separately from execution success. The authority caps all
physical sessions/forwards and time. No bigger chip allocation or app deployment.
