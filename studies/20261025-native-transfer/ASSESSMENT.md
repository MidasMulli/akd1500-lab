## What happened physically

Three plastic groups reside across seven sequential FNP3s: a source classifier and
two student banks whose identities encode outcome0/1. External outcomes ground only
the source. During student transfer the host supplies a fixed class0 descriptor,
no actual outcome bytes, and the same enable clock for both students. Each transfer
reads the preceding native query-output SRAM pointer directly. The native source
prediction and student recall feed the fixed error/valence feature circuit; the
native winner selects the record and the native swap rule changes its connections.

After transferring four associations, shuffled exams mask the teacher's plastic
cue code. The teacher's returned class bits are00 and its derived plastic potentials
are zero, while students answer from their own stored connections. This is answer-
path silence: the source NPU and its fixed raw-key routing helpers still run.

Two further externally grounded source facts are then added and transferred under
the same constant class. Students retain the original associations and answer all
six keys in a sealed final ordering. Unknown source keys6/7 do not alter either
student RAM. Queries/exams leave every bank RAM unchanged. All fixed helpers and
fixed routing RAM remain unchanged throughout each cell.

## Verification, repairs and limits

Every input, returned packet, descriptor class, source pointer and complete RAM
boundary matches separate Python bit-set and C++ packed replays. The portable
archive checks all qualified cells and the original62-forward failure prefix;
eight semantic corruptions are rejected beyond hash checks. Executed public source

Four compiler/authoring failures and one physical actor failure are preserved. The
wide signed code initially selected an FNP2 record track outside this adapter's

A prospective role-based carry rotation repair passed a new CPU gate before the
fresh physical gate. It adds no data-dependent host decision. See AMENDMENT01.md.

Twenty-four plastic records and232 fixed helper records across the three learning
groups; four additional groups implement fixed coding/routing. Bank identities,
feature representation, source grounding and error rule are designed. No whole-chip
utilization, simultaneous electrical execution, indefinite self-scheduling, power-
loss persistence or calibrated efficiency claim. Mode histories are instrument
journals. Final bits/RAM are read back; intermediate features and teacher per-record
responses are derived. The source first learns external facts; the students learn
from its native predictions. Functional CPU controls also pass.
