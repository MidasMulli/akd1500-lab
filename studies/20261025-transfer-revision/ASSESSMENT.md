# Learned knowledge can be revised across native memory groups

Three initializations pass all twelve reversals: **3,456/3,456 post-transfer
teacher-silent queries**, versus2,592/3,456 in each trained control. The source
receives external changed facts, corrects its own associations natively, and its
predictions then revise two student banks through constant-class transfer. No
outcome answer is supplied by the host during student transfer.

This extends the previous acquisition/independent-storage result with repeated
revision. It remains a four-cue synthetic experiment with designed representation,
roles and objective. Strong CPU teacher/student dictionaries also pass3,456/3,456;
it establishes no efficiency advantage, general memory management or autonomy.

associations are learned and48 teacher-silent prefix exams pass before ablation.

positive/complement evidence updates only the source bank. Each cycle includes
source probes, student exams before transfer, fixed query/transfer rounds and96

## Physical path and evidence limits

Seven sequential FNP3s form the pipeline: three learning groups hold24 plastic
records and232 fixed helpers; the other four groups perform fixed code/routing.
The source uses two classes; student plastic records occupy class0 and their bank
identities encode outcome0/1. Native source prediction selects positive versus
negative feature coding for the two students; their shared transfer descriptor
class remains zero. Host supplies raw keys, external source actual/complement
labels, and fixed per-role clocks. It never decodes the source response to select
a student, connection or threshold repair. One resident program per physical cell.

Source-negative features replace one query-key bit with a non-query sentinel.
Native competition selects the source association that changes. The student error
predicate and valence representation are designed, as is the phase marker used by
the cut-link control. No learned management objective or independent truth checking
is established. Confidently wrong teachers have not been tested in this study.

Every final native response, input, descriptor class/source pointer, full three-bank
RAM boundary and initial/final fixed route readback matches separate Python bit-set
and packed C++ references. Queries, exams, disabled banks and unknown-source events
leave the relevant RAM unchanged. Helpers stay fixed and plastic support remains
inside its110 coded positions. Teacher-silent exams mask source plastic cue input;
the source NPU and its key-routing helpers still run. Mode clocks/counters are own
instrument journals, not electrical CSR/bus traces. Intermediate features and
teacher per-record responses are derived; final student bits and stored RAM are
read back. Visual camera, geometry, glow and event timing are schematic.

## Execution and closeout

The staged first-seed one-cycle native gate passed before its controls; the full
twelve-cycle native run and controls were reviewed before the other two seeds.
Sixteen physical cells/25,408 native forwards complete. No compiler, authoring or
execution failure occurred in this series. Lower control/usefulness scores remain
scientific negatives with successful execution audits. Eight semantic corruptions
are rejected beyond digest checks. Executed public sources match their freezes.
The finite study is closed, no owned job remains, and the device was released.

No CPU speed/energy superiority, electrical concurrency, indefinite self-scheduling,
power-loss persistence, general capacity/eviction or whole-chip utilization claim.
The separate overloaded-bank capacity failure remains unresolved. A useful next
boundary is teacher credibility: can a memory-management group reject bad teaching
using independent outcome evidence without being given a privileged correctness bit?
That is a future hypothesis, not an outcome of this experiment.
